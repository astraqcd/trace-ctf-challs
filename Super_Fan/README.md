# Super Fan

**Category:** OSINT · **Difficulty:** easy · **Points:** 100 · **Type:** static

## Description

An analyst spotted this intensely dedicated football fan's vehicle at a local stop during a weekend drive through Minnesota. Can you piece together the digital trail left behind by this purple ride?

1. What is the first name of the dedicated fan who drives this car?
2. What city was this photo taken in?
3. What is the 5-digit ZIP code of that location?

**Flag format:** `trace{OwnerName_City_Zipcode}`, for example `trace{John_Minneapolis_55401}`. First name only.
