# Drug Market

**Category:** OSINT · **Difficulty:** medium · **Points:** 200 · **Type:** static

## Description

A travel vlogger walked through an open-air bazaar that sells something you cannot buy legally anywhere nearby. He never says where the camera is standing.

Name the valley and the district.

**Flag format:** `trace{Valley_District}`. Two fields, one underscore between them. Name the valley as a whole, not the basin inside it, and give the name on its own without the word "Valley".
