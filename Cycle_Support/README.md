# Cycle Support

**Category:** OSINT · **Difficulty:** easy · **Points:** 75 · **Type:** static

## Description

Somebody sells this page as wall art. It gives you the inventors, the company, the filing date and the serial number: everything except the number the patent was actually granted under.

Find that number.

**Flag format:** `trace{1234567}`

<details>

<details>
