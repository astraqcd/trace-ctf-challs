# Trace CTF: August Challenges

Public archive of challenge files for the August event.
Each challenge folder contains a `README.md` with the description,
downloadable artifacts under `files/`, and an organizer writeup under
`writeup/`.

Flags use the format `trace{...}`. Every challenge in this set is OSINT.

## Known gaps in this archive

Two challenges are archived in a state that cannot be played from these files
alone. Each one's writeup records the detail.

- **Night Shift** distributed a 788 MB synthetic call-record dataset over a
  hidden service. Neither the dataset nor the scripts that build it were ever
  committed, and the entry point was never decided.
- **Massacar**'s flag is a coordinate that no published source prints. See the
  organizers' note at the top of its writeup.
