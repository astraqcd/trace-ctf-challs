# I Love Cats

**Category:** OSINT · **Difficulty:** easy · **Points:** 50 · **Type:** static

## Description

Someone left a very cute cat on the internet. The owner is louder online than they think.

Find the public contact email address the cat's people hand out, and submit its MD5.

**Flag format:** `trace{md5}`. Lowercase hex, MD5 of the email address string with **no trailing newline**.
